# Assistant

The assistant is your long-lived conversation for each project. It's always available at the top of the sidebar — just click it and start talking.

Use it to manage your project: ask questions about the codebase, brainstorm ideas, plan work, or have it create tasks for you. The composer accepts text, slash-skill suggestions, and image attachments from the + button, paste, or drag/drop onto the composer. Locally sent messages spring from the composer into their normal conversation position; loaded or reconciled history does not replay the effect, and reduced-motion preferences disable it. Tapping send keeps the prompt focused when possible so the on-screen keyboard stays open; scrolling the conversation on mobile dismisses the keyboard. When creating a task, the assistant can also kick off a session on it immediately — the task is created and work begins in the background while you continue the conversation.

Unlike task sessions, which are scoped to a specific piece of work, the assistant sticks around. You keep talking to the same conversation over time. Long conversations open at their latest messages; scrolling to the top automatically loads previous history, or you can click "Load previous messages." Earlier messages are prepended without moving the message currently in view and remain available while the session is open. When you want a fresh start, click "New conversation" — the old one moves into a collapsible "Previous conversations" section.
