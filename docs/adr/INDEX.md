# Architecture Decision Records

Record an ADR when a library/tool/approach is **evaluated and rejected**, a **significant architectural choice** is made, or an existing decision is **revisited or reversed**. Use the format `NNN-slug.md`.

|-----|--------|---------|

| [019](019-server-generated-system-prompt-and-session-kinds.md) | Accepted | The server generates the Reins part of the system prompt and the node appends its environment; sessions have kinds (prompt, tools, environment) resolved by the server and sent in opening commands |
| [020](020-reloadable-node-hub.md) | Accepted | A dev handler reload rebuilds the node hub and closes its connections; the node redials and in-flight work recovers through retry-safe commits, reports and outbox replay. Deletes the process-owned link machinery |
| [021](021-explicit-node-reload.md) | Accepted | The node reloads on an explicit request (API, script, CLI) by pausing runs at clean points (`before_request`/`before_tool`) and restarting; the server resumes every run a node lost (reload, SIGTERM, crash), within a limit against crash loops. SIGTERM pauses instead of aborting |
| [022](022-shared-api-client-package.md) | Accepted | CLIs and tools call the server's HTTP API (no socket control listener) through `@reins/client`, shared with the browser app; backend types type-only by package name; non-JSON successes are errors and unknown `/api` routes a JSON 404 |
| [023](023-node-pairing-and-challenge-authentication.md) | Accepted | Remote nodes pair with single-use codes (one-winner redemption) and an Ed25519 key; the server challenges with `node.authenticate` inside the JSON-RPC link before `node.hello`; the transport decides whether a connection authenticates (the local socket does not); revocation is enforced at hello on every transport; the node's config is the commit point of `reins node pair` |
| [024](024-node-link-origin-from-the-upgrade-request.md) | Accepted | The `/nodes/link` WebSocket route checks a node's challenge signature against the origin of its upgrade request (`X-Forwarded-Proto`/`X-Forwarded-Host`, first values, else the request; as http(s)), with no configured public URL; under the private-network trust model the headers need not be trusted, and the binding still refuses a signature made for another server origin |
| [025](025-node-version-handshake.md) | Accepted | A node bundle's `node.hello` carries its `buildId`; the reply has a kind (`ready`, `update {buildId, sha256, bunVersion}`, `error {code, message}`), parsed tolerantly on both sides; after authentication, a node on another build than the server's is told to update before versions are compared; it installs the build, flips `current` and exits for its launcher to restart it. Defines the bootstrap surface that changes only additively |
| [026](026-sources-managed-on-the-server.md) | Accepted | The server's `sources` table is the only record of a node's checkouts, managed on the server (project form, `POST /api/projects/:id/sources`, `reins source`); the node keeps no list and runs in the path it is sent. Reverses the node-declared sources (`reins node source`, the hello's `sources`, node-side enforcement): under the trust model a node-side allowlist protects nothing |
| [027](027-node-end-of-the-connection-in-the-node-package.md) | Accepted | The node end of the connection moves from `@reins/node-protocol` into `@reins/node` as one module, `connectNode(node, transport, {nodeId, key?, buildId?, onState?, onUpdate?})` over a `Transport` (per-socket protocol, `Node` wiring and redial private to it); the protocol keeps what both ends share; scripted test nodes are stand-in `Node`s on the real `connectNode`. Amends 014 |
| [028](028-removing-a-node-abandons-it.md) | Accepted | Removing a node marks it removed and keeps its row, sources and sessions: it is refused at hello and hidden from lists and the default source; its sessions stay readable, refuse new work until moved to a live node, and queued work and running runs fail; no longer refused while it holds sources |
| [029](029-sessions-on-the-server-nodes-host-tools.md) | Accepted | Running sessions move to the server (AgentHarness 0.85, server storage, model runtime and credentials), kept across handler reloads in a process-owned runtime map with 3-minute idle eviction and a process-owned database connection; the outbox goes (Pi's admission is the record); every node is a tool and file host (a remote `ExecutionEnv`, execs that survive a dropped link); the environment is the server's `~/.agents` plus the checkout's; no compatibility path. Amends 013, 015, 019, 020, 021; supersedes the outbox of 010 |
