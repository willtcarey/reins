# Internal node seam

`packages/node/src/contract.ts` is the isolated `@reins/node/contract` export of a separately buildable node package. It contains a versioned semantic vocabulary for session open, prompt, steer, abort, pending resume, typed results and observations. It imports no server, Pi or browser modules; Oxlint restricts the contract's imports to `zod` and backend imports to the contract export. Future daemon implementation belongs elsewhere in `packages/node/src/`, not in this export. Version 1 is **not** a network protocol: no handshake, framing, correlation, ordering, delivery guarantee or serialized runtime event payload is promised. Change schema meaning with a version bump; negotiate incompatible versions closed when transport exists.

`packages/backend/src/runtimes/node-execution.ts` resolves a session's persisted source and selects the internal execution adapter. Creation policy selects the default internal source, and `session-store.ts` requires an explicit source. Child sessions inherit their caller's source. `session-manager.ts` still constructs the in-process Pi runtime and owns local broadcast, lifecycle and storage. Unsupported nodes fail before local execution. Files, git, resource expansion and DB-backed tools remain local; this seam does not make the server repo-independent. Canonical Pi state remains in server SQLite and must be proven transportable before a daemon is added. See `docs/plans/node-architecture.md`.
